# VolSkip

**Переключение треков удержанием кнопок громкости — без рута.**

Удерживаешь **Vol+** — следующий трек, **Vol−** — предыдущий. Короткое нажатие по-прежнему меняет громкость. Работает с любым плеером (Spotify, YouTube Music, Poweramp, VLC и т. д.), потому что отправляется стандартная медиа-клавиша.

🇬🇧 [English version](README.md)

## Возможности

- Долгое нажатие **Vol+** → следующий трек, **Vol−** → предыдущий
- Короткое нажатие — обычная громкость
- Работает только пока играет музыка — громкость звонка и уведомлений не трогает
- Настраиваемое время удержания (200–1100 мс) и вибро-отклик
- Крошечный (~30 КБ), без интернета, рекламы и слежки
- Интерфейс на английском и русском

## Установка

1. Скачай `VolSkip.apk` из [последнего релиза](../../releases/latest).
2. Установи (разреши установку из браузера / файлового менеджера, если попросит).
3. Открой VolSkip → **Открыть настройки спец. возможностей** → включи **VolSkip**.

> **GrapheneOS / Android 13+:** если переключатель серый, сначала открой *Настройки → Приложения → VolSkip → ⋮ → Разрешить ограниченные настройки*, потом включи сервис.

Нужен Android 12 (API 31) или новее.

## Как это работает

VolSkip — это `AccessibilityService` с `canRequestFilterKeyEvents`. Он видит события кнопок громкости раньше системы:

1. При нажатии, если `AudioManager.isMusicActive()` истинно, событие перехватывается и запускается таймер.
2. Если кнопку держат дольше порога — через `AudioManager` отправляется `KEYCODE_MEDIA_NEXT` / `KEYCODE_MEDIA_PREVIOUS`.
3. Если отпустили раньше — выполняется обычный шаг громкости.

Содержимое экрана сервис не читает, доступа к сети у приложения нет.

## Ограничения

- **При выключенном экране** Android отдаёт кнопки громкости активной медиасессии раньше, чем их увидят сервисы спец. возможностей, и поведение зависит от устройства и прошивки. Если на твоём телефоне при погасшем экране не срабатывает — это ограничение ОС, которое приложение без привилегий не обойдёт.
  - В кастомных прошивках (LineageOS / crDroid) это уже встроено: *Настройки → Кнопки → Управление музыкой кнопками громкости*.
  - С рутом можно сделать на системном уровне через модуль LSPosed / Magisk.
- Если музыка на паузе, кнопки работают как обычно.

## Сборка из исходников

```bash
git clone https://github.com/maminks/vol-chande-buttons
cd vol-chande-buttons
gradle assembleRelease        # или открой папку в Android Studio
```

Нужно: JDK 17, Gradle 8.10+, Android SDK 35. Результат — `app/build/outputs/apk/release/app-release.apk` (подписан debug-ключом — для сайдлоада подойдёт; для распространения используй свой keystore).

Каждый пуш собирается GitHub Actions; пуш тега `v*` публикует релиз с этой версией.
